# Example: Set Up an English Tutor

1. Create a new ChatGPT Project named **English Tutor**.
2. Open its Instructions and paste the full content of [project-instructions.md](../templates/project-instructions.md).
3. Optionally add learning materials and a student profile inside the Project.
4. Start a conversation, optionally using voice mode.
5. Let the tutor ask one question at a time and practice from uploaded material.
6. At the end, request a written summary and keep it available for later sessions.

**Important:** The Tutor Core and English module are source files for maintaining the prompt; ChatGPT Projects do not resolve references to GitHub Markdown files automatically. Use the standalone Project Instructions file.

**Privacy:** Do not add identifiable student details to the public repository.
