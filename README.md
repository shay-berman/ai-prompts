# AI Prompts

A reusable collection of prompts and instructions for ChatGPT Projects.

## Available frameworks

- [AI Private Tutor Framework](tutors/README.md) — a reusable Tutor Core and subject-specific English module, with a standalone ChatGPT Project prompt.

## Quick start

Open [English Tutor Project Instructions](tutors/templates/project-instructions.md), copy the entire file, and paste it into the Instructions of a new ChatGPT Project.

## Privacy

This repository is public. Never commit identifiable student information, completed student profiles, or private learning records. Keep these inside private ChatGPT Projects.
